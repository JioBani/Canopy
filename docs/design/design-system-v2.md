## 0. 왜 다시 만드나

Canopy 는 "Jira 가 안 읽혀서" 만든 도구다. 그런데 v1 도 안 읽힌다.

| 관찰된 문제 (2026-11-21 운영 화면) | 원인 | v2 규칙 |
|---|---|---|
| 트리 제목이 `데미…` `터미…` 3글자에서 잘림 | 진행바(4칸)+% 가 제목 폭을 먹음, 13px | 제목이 행 폭의 우선권을 가진다. 진행률은 숫자 하나로 축소 |
| 라벨·메타가 10.5~12px, 연회색/핑크 | 장식 우선 배치, `ink-3 #A89FA4`(대비 2.6:1) | **콘텐츠 텍스트 최소 14px**, 메타 최소 13px, 회색은 대비 4.5:1 이상만 |
| 이슈 상세에서 설명/요구사항/작업/로그가 한 덩어리 | 섹션 구분이 1px 선 하나, 모두 흰 배경 | **회색 캔버스 위 흰 카드**로 섹션을 물리적으로 분리 |
| 본문 줄 길이 950px+ | 상세가 `max-w-5xl` 전폭 | 읽기 컬럼 최대 760px, 속성은 우측 레일로 |
| 완료=핑크, 진행중=복숭아 | 브랜드색을 상태색으로 재사용 | 상태색은 의미색(초록/파랑/회색/빨강), 브랜드색은 선택·포커스·주요버튼만 |
| 메이플체 제목 | 둥근 디스플레이체, 긴 한글 제목에서 무거움 | 제목도 Pretendard. 메이플체는 워드마크 "Canopy" 한 곳만 |

## 1. 원칙 (우선순위 순)

1. **텍스트가 주인공.** 크기·대비·줄길이가 레이아웃보다 먼저 정해진다. 장식이 텍스트 폭을 먹으면 장식을 뺀다.
2. **경계는 면으로.** 다른 종류의 정보는 다른 면(캔버스 회색 / 카드 흰색 / 우물 회색)에 놓는다. 선 하나로 구분하지 않는다.
3. **색은 의미 하나에 하나.** 브랜드(선택·액션), 상태, 레이어(계층 타입)는 서로 다른 색축이다. 메타 텍스트에 색을 쓰지 않는다.
4. **잘라내지 말고 줄바꿈.** 요구사항 문장·작업 제목은 2줄까지 보여준다. 말줄임은 트리 같은 고밀도 내비에서만.
5. **조용한 기본값.** 테두리·그림자·라운드는 최소. 강조는 굵기와 크기로.

### 2.2 타이포그래피

- 서체: **Pretendard Variable** 단일. 숫자는 `font-variant-numeric: tabular-nums`.
- 모노: `"JetBrains Mono", "D2Coding", ui-monospace, Consolas, monospace` — 티켓키·코드에만.
- 한글 가독: `word-break: keep-all; overflow-wrap: anywhere;` 를 본문 기본으로.

| 토큰 | size / line-height / weight | 용도 |
|---|---|---|
| `title` | 26 / 36 / 700, -0.02em | 상세 제목 |
| `heading` | 18 / 26 / 700, -0.01em | 섹션 카드 제목 (설명, 요구사항, 작업 내용…) |
| `subheading` | 15 / 22 / 700 | 그룹 제목(UR 그룹), 다이얼로그 제목 |
| `body-reading` | 15 / 26 / 400 | 마크다운 본문, 요구사항 본문 — **읽는 글** |
| `body` | 14 / 22 / 400·500 | 목록 행, 트리, 컨트롤, 요구사항 문장 미리보기 |
| `label` | 13 / 18 / 600 | 속성 라벨, 섹션 내 소제목, 탭 |

### 2.3 간격 · 크기 · 라운드

- 4px 그리드: `4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48`.
- 컨트롤 높이: `sm 28` / `md 36` (기본) / `lg 40`. 아이콘 버튼 = 높이와 같은 정사각.
- 행 높이: 트리 `34`, 목록 행 최소 `44`(2줄이면 자연 확장), 속성 행 `36`.
- 카드 패딩: 헤더 `16 20`, 바디 `20`. 카드 간 간격 `16`.
- 라운드: 컨트롤 `6`, 카드·팝오버 `10`, 칩 `6`, pill `999`.
- 그림자: 카드 없음(테두리만). 팝오버·다이얼로그만 `0 8px 24px rgba(16,24,40,.12)`.
- 아이콘: 16px 기본(트리·행), 14px 칩 내부, 18px 섹션 헤더.

## 3. 컴포넌트 규칙

- **섹션 카드** `Section`: 흰 면 + `border` + radius 10. 헤더 = 아이콘(18) + `heading` + 개수 pill + 우측 액션(ghost sm 버튼). 헤더와 바디 사이 `border` 1px.
- **속성 필드** `PropertyRow`: 라벨(`label`, text-2) 위/왼쪽 + 값 컨트롤(`body` 500). 값은 칩 형태로 상태 아이콘·색 포함. 실수 방지 가드(화살표로만 열기)는 유지.
- **상태 칩** `StatusChip`: bg+fg+아이콘+이름. 높이 24, 패딩 0 8, `label` 13/600.
- **타입 칩** `LayerChip`: 레이어 soft 배경 + ink 글자 + 픽셀 아이콘.
- **티켓키** `TicketKey`: 모노 13, text-3, 배경 없음. 클릭 시 복사(툴팁 "복사됨").
- **개수 pill** `Count`: 20 높이, `micro`, bg `--surface-sunken`, fg text-2.
- **요구사항 행** `UrRow`: [상태아이콘16] [키(모노13 text-3, 문장 앞 인라인 — 고정폭 칸 금지) + 문장 `body` text-1, 전폭 2줄 clamp ／ 아래 메타 줄: 커버리지(meta, 미연결이면 danger "연결된 작업 없음")] [›]. 펼치면 문장 clamp 해제 + 아래에 우물(본문·설명) + "연결된 작업" 하위 리스트. 접힘/펼침 모두 문장은 한 번만 보인다.
- **작업 행** `TaskRow`: [상태칩] [키] [제목 `body` 500] … [도메인 칩] [담당 아바타].
- **트리 행** `TreeRow`: 34px, 들여쓰기 16/단계, [▸][타입아이콘16][제목 14 flex-1 truncate][진행률 meta tabular, 100%면 완료색]. hover 시에만 + / ⋯. 4칸 진행바 폐지.
- **버튼**: primary(brand 배경 흰 글자) / secondary(흰 배경 border-strong) / ghost / danger. 높이 36 기본, 라벨 14/600.
- **입력**: 높이 36, border-strong, radius 6, 포커스 = 2px brand 링(offset 1). placeholder 는 text-3(정보성 금지).
- **마크다운** `Markdown`: `body-reading`, h1 20/h2 17/h3 15 700, 문단 간 12, 표 14px, 코드 모노 13 sunken 배경(핑크 배경 폐지).

## 4. 구현 순서 (승인 후)

1. `src/index.css` 토큰 교체 + Tailwind `@theme` 매핑(`text-title`, `text-body` 등 타입 유틸 정의). 임의 px 클래스(`text-[13px]` 등 123곳) 제거.

3. 레이아웃: TopBar, Sidebar/Tree, Detail(헤더·2컬럼·속성 레일).
4. 화면: 세부기능(UR/작업 카드), 작업(체크리스트·연결 UR·선제조건·작업로그), 컨텐츠/기능(ChildNav), 마스터데이터.
5. 보드·대시보드·다이얼로그·검색·로그인.
6. E2E 셀렉터(`data-testid`) 보존 확인 → 스크린샷 비교.
